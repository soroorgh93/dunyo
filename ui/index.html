      Who is on the chain

      Each actor holds a real Ed25519 key pair; its address is the last 20 bytes of the SHA-256 of its public key. Every transaction is signed, verified, executed by a smart-contract rule and sealed in a block with a Merkle root and a state root.

      Checking…

      Dunyo works fully without any AI service. With a free local model it also writes friendlier explanations (every sentence is fact-checked against the data) and answers any follow-up question.

      1. Install Ollama from ollama.com (free, runs on your computer, private).
      2. In a terminal run: ollama pull llama3.2
      3. Done — Dunyo finds it automatically. No key needed.
      Use a cloud model instead (optional)

      Blockchain (optional)

      By default reports are sealed on a local tamper-evident ledger (or an in-process Ethereum chain). To publish on the public Sepolia test network, enter an RPC URL and a test-wallet key — never a real wallet.
